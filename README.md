# Tesis — memoria del proyecto

- Repositorio de notas, hechos y decisiones.
- Memoria en archivos Markdown.
- Notas breves. Viñetas y frases cortas.
- Fuente de referencia del proyecto: este repositorio.
- Cada hecho debe indicar su fuente.
- Cada decisión debe indicar fecha y motivo.
- Separar: confirmado, propuesto y pendiente.
- Una sugerencia del asistente no equivale a una decisión de Sonia.
- Las correcciones conservan el historial en Git.
